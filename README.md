# Email System (Gmail Replica)

## 📌 Overview
A fully responsive Email Replica Application simulating real-world email client functionality with added productivity tools.

## 🚀 Features
- 📥 Inbox layout & email listing
- 📧 Message view
- 🧭 Intuitive navigation
- ✅ Task Manager
- 🌳 Organizational Tree
- 📅 Meeting Scheduler

## 🛠 Tech Stack
- HTML / CSS / JavaScript 
- React / Next.js / Postgres / 

## 🎯 Purpose
To replicate a real-world email system while integrating productivity features for better task and team management.
